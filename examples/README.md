# Examples

These are complete outputs generated by AzVerify skills, demonstrating what each skill produces. All examples were generated using Claude Opus 4.6.

## Scenarios

| Folder | Description | Skills Demonstrated | Key Patterns |
|--------|-------------|-------------------|--------------|
| [azure-to-diagram-contoso-voting/](azure-to-diagram-contoso-voting/) | Reverse-engineered from a live Azure App Service deployment | `azv-azure-to-diagram`, `azv-azure-to-bicep` | App Service + Key Vault + Storage + EventGrid, managed identity, hub-and-spoke diagram layout |
| [sketch-to-diagram-resourcegroup01/](sketch-to-diagram-resourcegroup01/) | Generated from an architecture sketch with VMs and Private Endpoints | `azv-sketch-to-diagram`, `azv-diagram-to-bicep`, `azv-bicep-whatif`, `azv-bicep-policy-check`, `azv-diagram-azure-sync` | VNet + Subnets, VM with NIC, Web App + Private Endpoint + DNS Zone, full validation pipeline |
| [description-to-diagram-securewebapp/](description-to-diagram-securewebapp/) | Generated from a text description of a WAF-protected web app | `azv-sketch-to-diagram`, `azv-diagram-to-bicep` | Application Gateway WAF_v2, VNet integration, SQL Private Endpoint, Key Vault, DNS Zone |
| [azure-to-diagram-contoso-notify/](azure-to-diagram-contoso-notify/) | Reverse-engineered from a live Azure Function App deployment | `azv-azure-to-diagram`, `azv-azure-to-bicep`, `azv-bicep-diagram-sync`, `azv-bicep-policy-check`, `azv-diagram-azure-sync` | Function App (FlexConsumption), Communication Services, managed identity + RBAC, full validation pipeline |

## What Each Example Contains

Every example includes some or all of:

- **`main.bicep` + `modules/`** — Modular Bicep templates ready for deployment
- **`*.bicepparam`** — Parameter file with descriptive comments and environment variable references for secrets
- **`*.drawio`** — Architecture diagram (open with the [Draw.io VS Code extension](https://marketplace.visualstudio.com/items?itemName=hediet.vscode-drawio) or draw.io desktop)
- **`original-request.md`** — The original source request that produced these outputs
- **`README.md`** — Pre-deployment verification report with checks, warnings, and deployment commands
- **`dependencies/`** — External dependency templates (resources that must exist before main deployment)
- **Validation reports** — Sync reports, what-if reports, policy compliance reports (in some examples)
