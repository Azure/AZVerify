# Getting Started with AzVerify

## Prerequisites

- Access to GitHub Copilot or Claude code.
- **VS Code** with [GitHub Copilot](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot-chat) installed
- **Azure subscription** with resources you want to document or deploy
- **Azure CLI or PowerShell** authenticated
- *optional, but recommended* - **VS Code** with [GitHub Copilot](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot-chat) installed

> Testing has been done with VSCode and GitHub Copilot, but any environment that can send the appropriate prompts to the skills should work. To work with Claude Code, the .github folder needs to be renamed to .claude.

## Install MCP Servers

AzVerify skills use MCP (Model Context Protocol) servers. Althoough the tool will fall back to native tools without, the MCP workflow can be quicker. Configure the following MCP servers: 

| Server | Purpose | URL / Install |
|--------|---------|---------------|
| **Draw.io MCP** | Create and parse architecture diagrams | `https://mcp.draw.io/mcp` |
| **Azure MCP** | Query live Azure resources | [Install through Azure skills or Azure plugin ](https://aka.ms/azure-skills)|
| **Microsoft Learn MCP** *(optional)* | Verify Azure documentation | `https://learn.microsoft.com/api/mcp` |

## Extensions

Use the [draw.io VS Code extension](https://marketplace.visualstudio.com/items?itemName=hediet.vscode-drawio) to open and edit `.drawio` files generated by the skills directly in VS Code.

## Add the Skills

Clone this repository (or add it as a submodule) so that `.github/skills/` is available in your workspace:

```bash
git clone https://github.com/Ba4bes/AzVerify.git
```

Optionally copy and paste the skills to a repository relevant to you.

The skills are automatically discovered by GitHub Copilot from the `.github/skills/` folder.

## Run Your First Skill

The easiest way to start is with **sketch-to-diagram** using a text description.

1. Pick a prompt from [example-prompts.md](example-prompts.md) 

2. Open Copilot Chat and invoke the skill:

3. The skill will:
   - Ask clarifying questions about your architecture
   - Verify Azure service availability against Microsoft docs
   - Generate a professional Draw.io diagram

4. Next, generate Bicep from the diagram:

   ```text
   /azv-diagram-to-bicep `<path-to-your-generated>.drawio`
   ```
